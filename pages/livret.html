Le jour J

Votre arrivéeen trois gestes.

1. Se garer

La résidence dispose de son propre parking, juste devant le bâtiment. Vous pouvez vous y garer librement, sans badge ni disque. Inutile de chercher une place dans le village : déchargez directement au pied de l'immeuble.

2. Entrer dans la résidence

L'accès se fait par un code à composer sur la porte d'entrée. Nous vous le transmettons par SMS ou WhatsApp la veille de votre arrivée, en même temps que le code de la boîte à clés.

Pourquoi pas ici ? Par sécurité. Un code écrit sur une page web peut être photographié et circuler. Nous préférons vous l'envoyer personnellement — et le changer entre deux séjours.

3. Récupérer les clés

Les clés vous attendent dans une boîte à clés sécurisée. Son emplacement exact et son code figurent dans le message que nous vous envoyons avant votre venue.

Le studio est prêt à partir de 16 h. Si vous arrivez plus tôt et que le logement est libre, écrivez-nous : nous faisons notre possible pour vous ouvrir en avance.

Vous ne captez pas le réseau ou vous êtes bloqué ?

Appelez-nous depuis un téléphone fixe ou demandez à un voisin. Nous restons joignables jusque tard le soir les jours d'arrivée.

Si vous partez en montagne

Prévenez toujours quelqu'un de votre itinéraire et de votre heure de retour prévue. Vérifiez la météo et le bulletin d'enneigement le matin même : en montagne, une belle matinée ne garantit pas une belle après-midi.

Le dernier matin

Votre départquatre gestes, et c'est tout.

Le studio doit être libéré avant 10 h. Si vous avez pris le forfait ménage, nous nous occupons du reste. Sinon, suivez les modalités convenues avec nous avant votre arrivée. Dans les deux cas, merci de :

  • Vider et ranger le lave-vaisselle. Lancez-le la veille au soir, rangez la vaisselle au matin.
  • Sortir les poubelles et les déposer au local dédié.
  • Sortir les draps du lit et les laisser dans le studio.
  • Laisser le lit ouvert, sans le refaire.

Puis remettez les clés dans la boîte à clés, refermez-la et brouillez les molettes.

Un mot avant de partir ?

Si le séjour vous a plu, un avis nous aide énormément — et si quelque chose vous a manqué, dites-le-nous franchement : c'est comme ça qu'on améliore le studio d'un séjour à l'autre. Une adresse que vous avez aimée dans la vallée ? Envoyez-la-nous, nous l'ajouterons à notre carnet pour les prochains.
